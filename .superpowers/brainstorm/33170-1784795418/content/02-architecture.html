架构选型

仪表盘如何读取 mymore 的本地数据？

A

独立 HTTP Server

新建一个 server.py/server.js，直接读取 SQLite 文件，提供静态页面 + API。类似 EverMem 的 proxy.js，但不需要代理——直连本地的 memory.db

browser → localhost:3456 → server.js → memory.db（直连 SQLite）
B

MCP Resource 扩展

在现有 MCP Server 中新增 resource/tool（如 get_statistics、get_timeline），前端通过 MCP 协议获取数据

browser → proxy → MCP stdin/stdout → memory.db

我推荐 A：独立 HTTP Server 更简单、更可靠，前端直连无中间层，和现有 MCP 服务器互不干扰。port 3456 沿用 EverMem 的习惯。
