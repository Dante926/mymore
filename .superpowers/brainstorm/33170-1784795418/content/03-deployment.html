部署方式

HTTP Server 如何启动？

A

集成到 Docker

在现有 docker-compose.yml 中新增一个 hub 服务，与 mymore-mcp 并列运行

docker compose up -d
# mymore-mcp（stdin/stdout）
# mymore-hub（:3456）
B

独立进程

不属于 Docker，在项目目录下手动 node server.js 或 python3 server.py 启动

cd mymore && python3 apps/mcp-server/src/hub.py
# 打开 http://localhost:3456

集成 Docker 的好处：一键 docker compose up 就全部启动，别人 clone 后开箱即用；但 hub 和 mcp 是两个不同协议的进程（HTTP vs stdio），可能增大镜像体积。

独立进程的好处：零耦合，不改现有 Dockerfile，启动灵活；但需要手动执行命令。
