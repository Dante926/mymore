技术栈选择

Hub Server 用什么写？

A

Node.js

和项目一致。用 built-in http 模块 + better-sqlite3（已有依赖），单文件搞定

优势

  • 复用项目已有依赖
  • 和 Docker 镜像同一运行时

劣势

  • Node.js 做 HTML 模板拼接比 Python 啰嗦
B

Python

标准库 http.server + sqlite3 + 多行字符串模板，零依赖

优势

  • SQLite 标准库原生支持
  • 字符串模板更简洁
  • 单文件约 200 行搞定

劣势

  • 多一种运行时依赖
  • Docker 镜像需装 Python

我推荐 B（Python）——因为 hub 的核心工作就是读 SQLite + 生成 HTML，Python 的标准库支持比 Node.js 更直接。dashboard.html 用 pure JS，server.py 用 pure Python，零额外依赖。
