mymore Memory Hub — 设计方案

架构

browser → http://localhost:3456 → hub.js → memory.db (SQLite)

docker compose up -d
├── mymore-mcp │ MCP stdio 服务
└── mymore-hub │ HTTP :3456 仪表盘

功能

📊 统计卡片
🔥 6 月热力图
📈 7 日柱状图
📝 记忆时间线
🔍 搜索过滤
📂 项目筛选

文件结构

apps/mcp-server/src/
├── bootstrap.ts # MCP 服务（不变）
└── hub/
├── server.js # HTTP 服务 + API + 静态文件
└── dashboard.html # 前端仪表盘

docker-compose.yml # 新增 hub 服务

API 接口

GET / → dashboard.html
GET /api/stats → { totalMemories, projects, activeDays, avgDaily }
GET /api/heatmap → [{ date, count }] 近 6 月
GET /api/growth → [{ date, count }] 近 7 日
GET /api/memories → [{ id, content, category, created_at }] 分页
GET /api/memories?q=关键词 → 搜索
GET /health → { status: 'ok' }
